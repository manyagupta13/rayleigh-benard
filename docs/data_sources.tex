\section*{Overview}
This document records exactly where every number in
\texttt{data/nu\_dataset\_model.csv} came from. Section~3.3 of Shreshthi \&
Pandey's paper (\emph{Turbulent Prandtl number in the near-wall region of
thermal convection}) trains a random forest regressor to predict the Nusselt
number $Nu$ from the Prandtl number $Pr$ and Rayleigh number $Ra$, using 55
data points drawn from five cited papers plus the paper's own simulations.
This document reproduces the relevant tables from every source used,
highlights which rows were kept, and comments on why the rest were left
out. The dataset was later extended beyond the paper's five citations with
four more papers that simulate the identical configuration
(Sections~\ref{sec:zzs2017}--\ref{sec:vdp2012}), bringing it from 59 to
194 rows. Two of those sources report $Nu$ only in figures; their values
were read from the vector graphics inside the PDFs
(Section~\ref{sec:extraction}).

\noindent Every included row describes the \emph{same} physical setup:
a closed 2D square box ($\Gamma=1$), no-slip velocity on all four walls,
isothermal top/bottom plates and adiabatic sidewalls. References 1--4 share
one spectral-element code: several of their rows report the exact same $Nu$
to the decimal at the same $Pr, Ra$, which is only possible if it is the
same simulation reused across papers. References 5--10 use four other codes
(finite-difference and lattice-Boltzmann). Where independent codes simulate
the same $(Pr, Ra)$ their $Nu$ agree to a median of 1.5\%
(Section~\ref{sec:agreement}), which is the evidence that the pooled data
are homogeneous. Grid resolution differs between sources and does not need
to match: what matters is that each run is converged, which every source
checks (grid spacing versus Kolmogorov/Batchelor scale, points inside the
thermal boundary layer, agreement of independent $Nu$ definitions).

\section{Extracting values from figures}\label{sec:extraction}
For He et al.\ (2021) and van der Poel et al.\ (2012) the plots are stored
in the PDF as vector graphics, so the markers' exact coordinates can be read
from the drawing commands instead of estimated from a picture
(PyMuPDF \texttt{get\_drawings}):
\begin{enumerate}[leftmargin=1.6em, itemsep=0.3em]
\item Axis calibration from the tick marks and tick labels drawn in the
same figure (e.g.\ He Fig.~5(a): 0.01 in $Nu/Ra^{0.3}$ per 42.01\,pt;
48.27\,pt per decade of $Ra$).
\item Each marker identified by its fill or stroke colour and shape, which
map one-to-one to the legend; legend entries removed by position. Open
markers drawn as one combined path were split by clustering vertices.
\item Marker centre = bounding-box centre (squares, circles, diamonds,
triangles) or vertex mean (regular pentagons, i.e.\ the circumcentre).
\item Every marker lands within 0.002 decades of a nominal $Ra$ value,
confirming the calibration. $Nu$ then follows from $Nu/Ra^{0.3}$ times
$Ra^{0.3}$. Two He markers drawn on top of each other were averaged (they
differ by 0.3\%).
\end{enumerate}
The positional uncertainty (about 0.1\,pt) corresponds to under 0.2\% in
$Nu$. Raster figures (Yang et al.\ 2021, He et al.\ Fig.~5(b)) were not
digitized.
